Tabla de multiplicar con PHP

El entregable de esta práctica es index.php, que se ejecuta en el servidor Apache de XAMPP. Como GitHub Pages solo sirve archivos estáticos y no interpreta PHP, esta ficha reproduce el mismo resultado con JavaScript y muestra el código original.

Para ver la versión real: copia la carpeta a htdocs, inicia Apache desde el panel de XAMPP y abre http://localhost/tabla/index.php?num=2.

Cómo llega el número al script

Todo lo que sigue al signo ? en la dirección es la cadena de consulta. Cada parámetro es un par nombre=valor y PHP los deja listos en la superglobal $_GET, usando el nombre como llave: 

http://localhost/tabla/index.php?num=2&hasta=10
                                    │        │
                                    │        └── $_GET['hasta']
                                    └── $_GET['num']

Lectura y validación

Los valores de la URL siempre llegan como texto y los escribe quien sea desde la barra de direcciones, así que se comprueban antes de usarlos: 

<?php
// isset() evita el aviso «Undefined array key» si no viene el parámetro
$numeroCrudo = isset($_GET['num']) ? trim($_GET['num']) : '';

if ($numeroCrudo !== '') {
    $numeroValidado = filter_var($numeroCrudo, FILTER_VALIDATE_INT);

    if ($numeroValidado === false) {
        $error = 'El valor «' . $numeroCrudo . '» no es un número entero.';
    } elseif ($numeroValidado < NUM_MINIMO || $numeroValidado > NUM_MAXIMO) {
        $error = 'El número debe estar entre ' . NUM_MINIMO . ' y ' . NUM_MAXIMO . '.';
    } else {
        $numero = $numeroValidado;
    }
}

Generación de las filas

El ciclo arma un arreglo y la plantilla HTML solo lo recorre, de modo que el cálculo no queda mezclado con las etiquetas: 

$filas = [];
for ($i = 1; $i <= $hasta; $i++) {
    $filas[] = [
        'multiplicador' => $i,
        'resultado'     => $numero * $i,
    ];
}
<?php foreach ($filas as $fila): ?>
    <tr>
        <td><?= esc($numero) ?> &times; <?= esc($fila['multiplicador']) ?></td>
        <td><?= esc($fila['resultado']) ?></td>
    </tr>
<?php endforeach; ?>

Detalles que se cuidaron

  • Cada dato que se imprime pasa por htmlspecialchars(), para que un valor con etiquetas en la URL no se inyecte en la página.
  • El formulario usa method="get": al enviarlo, el propio navegador construye la URL con ?num=...&hasta=..., que es justo la forma en que el profesor pidió recibir el parámetro.
  • Sin parámetro la página no truena: muestra el formulario y una indicación de cómo escribir la dirección.
  • hasta es opcional; si no viene o viene mal, se usa 10 sin marcar error.
